# کتابخانهٔ فارسی، دیالوگ قطعه، خروج ویندوز و اتوماسیون

این انتقال فقط در `my-develop` توربو انجام شده است. سورس پروژهٔ اصلی، برنچ
`develop`، VM و اصلاحات داخلی RTL توربو تغییر نکرده‌اند.

## نام رسانه‌ها و جست‌وجو

- فرهنگ `src/lib/libraries/translations/fa.js` از پروژهٔ قبلی منتقل شده و نام
  اسپرایت‌های مخصوص توربو نیز پوشش داده شده است؛ «Kiran» همچنان «کایرن» است.
- `translate-library-name.js` فقط برای کتابخانه‌های داخلی sprites/backdrops/sounds
  در زبان فارسی فراخوانی می‌شود؛ عربی و انگلیسی نام اصلی را نشان می‌دهند.
  این پیاده‌سازی کاتالوگ‌ها را هم‌زمان و زودهنگام import نمی‌کند؛ بارگذاری تنبل
  کتابخانه‌های توربو حفظ شده است.
- `components/library/library.jsx` نام ترجمه‌شده را نشان می‌دهد و جست‌وجو نام
  اصلی، نام فارسی، tag و توضیح را پوشش می‌دهد. نرمال‌سازی حروف ی/ک، اعراب،
  نیم‌فاصله و ارقام فارسی از `library-item-search.js` می‌آید.
- containerهای sprite/backdrop/sound نام رسانهٔ تازهٔ انتخاب‌شده را ترجمه
  می‌کنند. فایل‌های بازشدهٔ کاربر و نام‌های موجود در VM بازنویسی نمی‌شوند.
  کلید علاقه‌مندی، metadata کاتالوگ و MD5/آدرس دارایی اصلی حفظ شده‌اند.
- کلاس library و thumbnailها همچنان مسیر محلی را به کار می‌برند؛ این تغییر
  وابستگی جدید یا درخواست شبکه برای ترجمه ایجاد نمی‌کند.

## دیالوگ ایجاد قطعه

`custom-procedures.css` محدودیت عرض/ارتفاع بر اساس overlay، اسکرول داخلی، فضای
کمتر، preview کوچک‌تر و کارت‌های کم‌ارتفاع با آیکون ۳۲px دارد. محدودیت ارتفاع
`calc(100% - 16px)` است تا به مشکل vh در WebView برخورد نکند.
فراخوانی خودکار `focusLastEditor_` هنگام ساخت دیالوگ از container حذف شده است؛
انتخاب دستی فیلد و افزودن ورودی همچنان قابل استفاده‌اند. منطق تولید mutation،
بلوک‌های سفارشی و رفتار RTL تغییر نکرده‌اند.

## تأیید خروج Windows

`desktop/window-config.cjs` از زبان فعلی `document.documentElement.lang` برای
ساخت دیالوگ فارسی، عربی یا انگلیسی استفاده می‌کند. عنوان برنامه TurboWarp FA
باقی است. Enter پیش‌فرض و Escape روی انصراف‌اند؛ چند کلیک روی ضربدر فقط یک
دیالوگ می‌سازد. تأیید، پنجره را destroy و app را quit می‌کند. خطا ثبت می‌شود و
پنجره باز می‌ماند؛ تلاش بعدی مجاز است. `build-windows.mjs` فایل helper را کنار
main.cjs در هر دو بسته کپی می‌کند؛ sandbox و contextIsolation حفظ شده‌اند.

## GitHub Actions

- `node.js.yml`: CI عمومی فقط workflow_dispatch/workflow_call دارد؛ push/PR
  عمومی روی شاخهٔ سفارشی دیگر بیلد کامل ایجاد نمی‌کند. Node 24 استفاده می‌شود.
- `restore-point.yml`: روی هر push به my-develop، runner از GitHub API برای ساخت
  `restore-point-my-develop-<SHA کامل>` و prerelease سورس استفاده می‌کند. تگ موجود
  فقط با همان SHA معتبر است؛ جابه‌جا نمی‌شود. source ZIP/tar.gz را GitHub می‌سازد؛
  فایل یا تگ بازیابی محلی تولید/آپلود نمی‌شود. make_latest برابر false است.
- `custom-release.yml`: افزایش واقعی نسخهٔ ریشه در push، یا تگ `vX.Y.Z-fa.N`،
  بیلد آفلاین را روی windows-2022 اجرا می‌کند. ریلیز شامل ZIP محتویات `build/`،
  دو نصب‌کنندهٔ x64/ia32 و SHA256SUMS است؛ ZIP، APK نیست. تگ باید با نسخهٔ package
  مطابقت داشته و به کامیتی از شاخهٔ my-develop اشاره کند. نسخهٔ ثابت/کاهش نسخه
  ریلیز خودکار ایجاد نمی‌کند. npm publish اجرا نمی‌شود.
- مسیرهای monorepo در workflow قبلی با مسیر ریشهٔ توربو تطبیق داده شده‌اند؛
  بیلد اضافهٔ workspace حذف شده و Inno Setup 6 یا 7 شناسایی می‌شود.
- مجوز نوشتن contents فقط در jobهای انتشار/بازیابی است. secrets دستی لازم نیست؛
  GITHUB_TOKEN خود runner استفاده می‌شود. محدودیت‌های حساب/Actions همچنان اعمال می‌شوند.
- develop و تنظیم default branch تغییر نمی‌کنند. نمایش دکمهٔ اجرای دستی در UI
  به وجود workflow روی default branch وابسته است؛ این محدودیت روی triggerهای
  push/version/tag اثر ندارد. [مستند GitHub](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#workflow_dispatch).

## آزمون

۷۸ تست واحد پاس شدند، شامل پوشش نام فارسی تمام رسانه‌های سه کتابخانه، جست‌وجو،
تأیید/انصراف/خطای خروج، جلوگیری از چند دیالوگ و تست واقعی اسکریپت تصمیم‌گیری
ریلیز در مخزن آزمایشی. اسکریپت بازیابی با API شبیه‌سازی‌شده از نظر ایجاد، اجرای
مجدد و رد تگ با SHA متفاوت تست شد؛ هیچ تگ محلی در تست‌ها ساخته نشد.

روی بیلد، Chrome دسکتاپ و شبیه‌سازی WebView با شبکهٔ خارجی مسدود: نمایش و
جست‌وجوی فارسی/انگلیسی، افزودن رسانه با نام فارسی، حفظ نام قبلی و رفت‌وبرگشت SB3
پاس شدند. دیالوگ قطعه در ارتفاع منطقی ۳۰۰px داخل صفحه قرار گرفت، اسکرول داخلی
داشت، ورودی خودکار فوکوس نشد و افزودن آرگومان/تأیید کار کرد.

در Electron هر دو معماری، تغییر زبان fa/ar/en به گزینه‌های درست تأیید خروج
رسید؛ انصراف پنجره را نگه داشت و تأیید فرایند را بست. API دیالوگ بومی در این
آزمون شبیه‌سازی شده است؛ ظاهر دیالوگ سیستم به‌صورت دستی بررسی نشده است.
تست روی گوشی واقعی و انتقال فایل به assets کلاینت در این مرحله انجام نشده‌اند.

بیلد اندروید و دو Setup موفق‌اند؛ ۱۶۹۱ فایل وب، حدود ۷۱٫۰۵ MiB، بدون source map
و با SHA256 یکسان در دو بستهٔ ویندوز. ۱۳۰۴ دارایی محلی و حذف ۱۵۰۰ فایل آموزشی
تأیید شدند. آزمون بریج/پیام جدید و کتابخانه‌ها/ویرایشگر لباس با شبکهٔ مسدود پاس شد.
lint فایل‌های جدید و تغییرات کتابخانه پاس است؛ خطاهای قدیمی setState در
componentDidMount کتابخانهٔ صدا و قالب‌بندی catch در desktop/main.cjs مانند
خطاهای منوی قبلی باقی‌اند. تغییرات جدید خطایی به آن‌ها اضافه نکرده‌اند.
